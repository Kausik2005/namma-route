Connect your Google Maps API key

  1. In the Google Cloud console, create a project with billing turned on.
  2. Enable Routes API (routing and traffic) and Maps JavaScript API (the map and its traffic layer).
  3. Create an API key. Under key restrictions, limit it to those two APIs and to the website where you host this page (for example http://localhost:8000/* or https://yourname.github.io/*).
  4. Paste it below. It is stored only in this browser.
Google bills Routes API per request. This page only calls it when you press Plan route or Find the best time, never in the background.

Directions

    Fuel estimates assume petrol at ₹103 a litre, 14 km/l for a car and 45 km/l for a two-wheeler. Tolls and metro fares come from Google where it has them.

    Trip times, alternatives, stop order and the traffic on each route come from the Google Routes API with traffic-aware routing. The traffic layer on the map is Google's live feed.
